# Dispatch export samples

Generated by `python scripts/export_dispatch_samples.py` with:

| Assumption | Value |
|---|---|
| As-of week | 25 Aug 2025 |
| Forecast horizon | +2 weeks (week of 08 Sep 2025) |
| Regional stock | 60% |
| Spraying crews | 8 |
| Bed capacity multiplier | 1.20× |
| Scope | all 60 wards; samples for the 8 highest-priority deficit wards |

Each ward has three files:

- `*_sms.txt` — ≤160-character field SMS
- `*_whatsapp.txt` — formatted WhatsApp message
- `*_brief.html` — self-contained printable commissioner brief

`scenario.json` records the exact inputs, required/available totals, deficits,
bed demand/capacity and the intra-city transfer list.

No network call or LLM is used. Regenerate with:

```bash
python scripts/export_dispatch_samples.py --stock 0.6 --crews 8 --capacity-mult 1.2
```
